# DPay balance inquiry (`Look/get_coin`)

GoldPay exposes DPay coin/balance query as:

`POST /api/v1/funding/balance-inquiry` (merchant API key).

GoldPay calls DPay upstream:

`POST https://payment.dpayvn.com/Look/get_coin` (override with `DPAY_LOOK_BASE_URL`).

## 1. Request (GoldPay)

`Content-Type: application/json`

Body:

| Field | Type | Required | Notes |
|--------|------|----------|-------|
| `find_date` | string | no | `YYYY-MM-DD HH:mm:ss`. If omitted, GoldPay generates current time in +7 format. |

Authentication:

`X-API-Key: <merchant api secret>`

## 2. Upstream (DPay) form fields

GoldPay sends:

| DPay field | Required | Source |
|------------|----------|--------|
| `merchant_num` | yes | env `DPAY_MERCHANT_NUM` (or override in provider config later) |
| `uid` | yes | env `DPAY_UID` |
| `find_date` | yes | request `find_date` (or generated by GoldPay) |
| `sign` | yes | computed by GoldPay using `DPAY_SIGN_*` + `DPAY_SECRET` |

Content-Type:

`application/x-www-form-urlencoded;charset=UTF-8`

## 3. Response mapping

Successful upstream response (`code = 1`) returns:

| Field | Description |
|-------|-------------|
| `data.coin` | available amount (VND) |
| `data.fcoin` | freeze amount (VND) |

GoldPay returns:

```json
{
  "success": true,
  "code": 1,
  "merchant_num": "100000101",
  "coin": "100",
  "fcoin": "100",
  "message": "ok"
}
```

On failure (`code != 1`), GoldPay returns:

```json
{
  "success": false,
  "provider_error": { "code": 1022, "message": "user error" },
  "raw": { ...upstream body... }
}
```

Use `docs/DPAY_ERROR_CODES.md` to understand DPay error codes/messages.
